# Installing Kids' Learning Studio

The easiest way: open **https://oluwasedago.github.io/kids-learning-studio/install.html** on the tablet. The
page recognises the device and shows only the steps for it. On a computer, scan the QR code on that page with
the tablet's camera.

The app installs from the browser ("Add to Home screen"). There is no app store, no account and no download
of personal data. Installing to the home screen makes it open full screen and helps the browser keep its data.

## Amazon Fire

1. In the **parent (adult) profile**, open the install page in the **Silk Browser**.
2. Tap the menu (⋮) and choose **Add to Home screen**.
3. Open Kids' Learning Studio from the home screen and follow the setup.

Status: to verify on a Fire tablet. Child profiles in **Amazon Kids** use their own restricted browser; whether
the app can be added and used there is not tested yet. Reading aloud depends on the voices the Fire has.

## Android tablet or phone

1. Open the install page in **Chrome**.
2. Tap the menu (⋮) and choose **Install app** or **Add to Home screen**.
3. Open the app from the home screen and follow the setup.

Keeping a child in the app: **Settings → Security → App pinning** (some devices: "Screen pinning"), then pin the
app from the recent-apps view.

## iPad or iPhone

1. Open the install page in **Safari**.
2. Tap **Share** (a square with an arrow) → **Add to Home Screen** → **Add**.
3. Open the app from the home screen and follow the setup.

Keeping a child in the app: **Settings → Accessibility → Guided Access → On**, then triple-click the top (or
home) button inside the app. For a better reading voice: **Settings → Accessibility → Spoken Content → Voices →
English**, download an "Enhanced" or "Premium" voice, then choose it in the app under Parents → Reading aloud.

## Computer

The app works in Chrome, Edge, Firefox and Safari for trying it out. Chrome and Edge can install it with the
install icon in the address bar.

## First start

The setup asks for:

1. The child's first name or nickname (optional) and **birth month and year** (never the full date).
2. A **4-digit parent PIN** (it opens the parent screen and unlocks items for today).
3. What should be switched on: a suggestion for the child's age, which you can change any time.

Or choose **Try the demo** (made-up data, PIN 1234) or **Restore from backup**.

## Backups and moving to a new device

Data lives only on the device. Make a backup now and then: **Parents → Backup → Back up now** (the app reminds
you). On a new device, install the app and choose **Restore from backup** on its first screen. The backup file
holds the child's first name, birth month and year and their progress: keep it private.
